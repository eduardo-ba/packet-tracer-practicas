# Prácticas de Redes con Packet Tracer

Este repositorio contiene un conjunto de prácticas realizadas en Cisco Packet Tracer, enfocadas en el diseño, simulación y configuración de redes para distintos escenarios. Cada práctica incluye archivos `.pkt` para abrir directamente en Packet Tracer, con el objetivo de simular conectividad, administración de red y aplicación de conceptos de LAN, VLAN, routers, switches y protocolos de red.

## Contenido de las prácticas

### 1. Conexión entre 4 universidades
- **Archivo:** `Conexion entre 4 universidades.pkt`
- **Objetivo:** Simular la interconexión de cuatro universidades mediante routers y enlaces WAN.
- **Aprendizaje:** Configuración de IPs, rutas estáticas, pruebas de conectividad entre múltiples redes.

### 2. Configuración de seriales
- **Archivo:** `Configucion de seriales.pkt`
- **Objetivo:** Practicar la configuración de interfaces seriales para enlaces punto a punto entre routers.
- **Aprendizaje:** Asignación de IPs a interfaces seriales, activación de enlaces, pruebas de conectividad.

### 3. Configuración de red de 4 universidades
- **Archivo:** `Configuracion de red de 4 universidades.pkt`
- **Objetivo:** Implementar una red completa que conecte cuatro universidades con routers y switches.
- **Aprendizaje:** Routing, VLANs, subredes y administración de tráfico entre redes.

### 4. Diagrama de red edificio 2
- **Archivo:** `Diagrama de red edificio 2 pt.pkt`
- **Objetivo:** Diseñar y simular la red interna de un edificio, incluyendo switches y VLANs.
- **Aprendizaje:** Configuración de VLANs, segmentación de red, conectividad interna.

### 5. Implementación de HSRP
- **Archivo:** `Implementacion de HSRP.pkt`
- **Objetivo:** Configurar HSRP (Hot Standby Router Protocol) para redundancia de routers.
- **Aprendizaje:** Configuración de HSRP, priorización de routers, pruebas de failover.

### 6. Práctica en simulador de direccionamiento
- **Archivo:** `Práctica en simulador de Direccionamiento con Router.pkt`
- **Objetivo:** Practicar la asignación de direcciones IP a múltiples dispositivos en una red simulada.
- **Aprendizaje:** Planificación de subredes, asignación de IPs estáticas y dinámicas, verificación de conectividad.

### 7. Práctica VTP
- **Archivo:** `Practica VTP.pkt`
- **Objetivo:** Configurar VTP (VLAN Trunking Protocol) para la propagación automática de VLANs entre switches.
- **Aprendizaje:** Configuración de VTP server y client, propagación de VLANs, administración de switches.

---

## Tecnologías utilizadas
Cisco Packet Tracer, LAN, VLAN, Routers, Switches, IP, DHCP, HSRP, VTP, Configuración de seriales, Simulación de tráfico.

---

## Uso
1. Descargar los archivos `.pkt` correspondientes.
2. Abrir en **Cisco Packet Tracer**.
3. Explorar la topología, revisar configuraciones y realizar pruebas de conectividad según los objetivos de cada práctica.

## Antes de abrir una práctica

Utiliza una versión de Cisco Packet Tracer compatible con el archivo; la versión de guardado no está documentada. Si aparece un aviso de incompatibilidad, ábrelo con una versión igual o posterior a la usada para guardarlo. Trabaja sobre una copia si quieres conservar el escenario original.
